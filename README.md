## 📁 Учебные проекты

### 🚚 Проект «Доставка заказов» (командная работа)
**Роль:** бизнес-аналитик

- **Выявление требований:** проводила ролевые игры, мозговые штурмы и семинары для сбора требований от 7 ролей (клиент, оператор, администратор, курьер, диспетчер и др.).
- **Документирование:** разработала документ «Концепция» (Vision/BRD), описала бизнес-цели, проблемы и чёткие границы MVP-продукта.
- **Моделирование:** построила контекстную диаграмму (Context Diagram) для определения взаимодействия системы с внешними API и смежными системами.
- **Результат:** сформирован полный пакет документации, успешно защищённый перед командой.

### 📅 Проект «Онлайн-запись» (индивидуальная работа)
**Роль:** бизнес-аналитик

- **Моделирование процессов:** описала текущие (AS-IS) и будущие (TO-BE) бизнес-процессы.
- **Моделирование данных:** выделила сущности предметной области, провела их валидацию по матрице CRUD, построила логическую модель данных (ER-диаграмму) со связями 1:M и M:N, составила словарь данных (Data Dictionary).
- **Артефакты:** каталог стейкхолдеров, луковичная диаграмма (Onion Diagram), глоссарий терминов.
- **Результат:** валидация сущностей по матрице CRUD позволила выявить и закрыть «слепые зоны» в правах доступа к данным.
